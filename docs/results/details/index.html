    Results: every table¶

    This page collects every table the benchmark produced, with enough context to read each one on its own. The chapters that discuss them carry the same tables beside the argument. Local measurements come from distinct saved runs on one 48 GB Mac; remote rows include network/provider latency, on one 67-query router question; chapter 5 describes the run. For the headline figures, start at Results: the short version.

    Scores count correct answers out of 67. Translated means the 39 non-English queries were first translated into English; direct means the classifier got the original text. ms/query is the mean wall-clock time per query, without model loading. Chapter 5 defines every column.

    Explore the interactive Pareto diagrams to find the fastest model above your own accuracy floor.

    C/G labels every classifier run: C = CPU, G = GPU, C+G = mixed CPU/GPU, C+N = CPU/Neural Engine, A = automatic CPU/GPU/Neural Engine placement, R = remote. Hover over the code for execution settings and evidence.

    Most tables sort when you click a column header; click again to reverse the order.

    OpenRouter: nine remote models¶

    All nine requested endpoints were measured on the same 67 queries, in translated and direct modes, on 3 October 2026. Translations and local results are retained from the earlier runs. Each endpoint received 106 distinct inputs, sequentially, with duplicate inputs reused across modes. Latency includes the network trip and provider processing; R means the provider did not disclose CPU/GPU placement or weight precision.

    Six endpoints use a native five-way choice. Respan's three endpoints support noul only: each request contains five independent yes/no questions using the same task descriptions. We choose the largest P(true), then normalize the five values for the routing report. This noul OVR readout is labelled separately; its values are not calibrated exclusive-choice probabilities. Choose OpenRouter API in the explorer's engine filter to select all nine endpoints. Its table shows the readout for each run.

    A fallback gate¶

The rows replay the benchmark's cached answers at each threshold. Fallbacks counts the queries sent on; mean ms is the cost per query averaged over all 67, where a query that falls back pays for both calls. The thresholds were chosen on the same queries they are scored on, so this is not a held-out test. Chapter 9 explains why the gate pays only on the original text.
